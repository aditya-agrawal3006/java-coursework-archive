# Java Coursework Archive

A curated selection of smaller Java exercises and projects from my programming courses at the University of Maryland. These projects focus on programming fundamentals, data structures, and object-oriented design.

| Project | Focus |
| --- | --- |
| [BinarySearchTree](projects/BinarySearchTree/src/) | Trees and recursion |
| [LinkedLists](projects/LinkedLists/src/) | Custom linked lists and iteration |
| [ClearCellGame](projects/ClearCellGame/src/) | Game logic and state management |
| [DiagramSystem](projects/DiagramSystem/src/) | Interfaces and composition |
| [MediaRentalManager](projects/MediaRentalManager/src/) | OOP and collections |
| [PhotoManager](projects/PhotoManager/src/) | Classes and data management |
| [PassportClass](projects/PassportClass/src/) | Object design and validation |
| [RecursionExercise](projects/RecursionExercise/src/) | Recursive programming |
| [ArrayUtilities](projects/ArrayUtilities/src/) | Arrays and methods |
| [JavaLoops](projects/JavaLoops/src/) | Loops and control flow |

Only relevant source files are included. Duplicate example folders, trivial practice files, submission metadata, compiled outputs, and incomplete implementations have been excluded from this curated archive.

**Note:** Some class and interface scaffolding was supplied as part of coursework. This repository is primarily for code review, rather than a unified runnable application.
